# Aldi Protein Kitchen

A small, mobile-friendly vegan meal planner for Aldi UK. Each recipe is designed to make two portions in 10–30 minutes, with an estimated minimum of 30g protein per portion.

## What it does

- Browse Italian, Indian, Mexican, Asian and Mediterranean meal ideas.
- Refresh the page of suggestions from a curated recipe collection.
- Add cooking batches; every batch makes one lunch and one dinner.
- Combine ingredients across selected recipes into one aisle-sorted shopping list.
- See Aldi product pack images and open the linked Aldi product listing.
- Adjust batch counts, tick off items, copy the list, or print it.

Meal selections and ticked shopping items are saved in the browser using local storage.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, set **Source** to **GitHub Actions**, and save. The workflow in `.github/workflows/pages.yml` deploys the static site whenever a commit reaches `main`.

The site URL will be `https://samwarb.github.io/aldi/` once the first Pages deployment succeeds.

## Nutrition and product images

Protein values use Aldi label information where available, plus typical estimates for fresh ingredients and pantry staples. They are estimates; recipes and product labels can change, so check the pack. Product pack images link directly to Aldi UK image assets, and each packaged ingredient links to its Aldi product page. Aldi availability and prices vary by store.
